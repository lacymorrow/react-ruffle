# react-ruffle — StackBlitz demo

A minimal Vite + React + TypeScript app that renders a Flash SWF using `<Flash />` from `react-ruffle`. Swap the `SWF` constant in `src/main.tsx` to point at your own file.

## Open it live

➔ **[Open in StackBlitz](https://stackblitz.com/github/lacymorrow/react-ruffle/tree/main/examples/stackblitz)**

## Run locally

```bash
cd examples/stackblitz
npm install
npm run dev
```
